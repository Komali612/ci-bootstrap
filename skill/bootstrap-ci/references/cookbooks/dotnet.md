# Cookbook: .NET / C# (dotnet CLI) — `build_system: dotnet`

Language-specific choices:
- **Setup:** .NET 8 SDK via `actions/setup-dotnet`.
- **Sonar:** the .NET scanner is a global tool that *wraps a build* and runs on a
  JVM, so this cookbook contributes several named Sonar steps (set up JDK →
  install scanner → begin → build → end). Each carries the Sonar guard, so the
  whole group is skipped until `SONAR_TOKEN` is set.
- **Dockerfile:** the `ENTRYPOINT` dll is app-specific — left as a `TODO`.

Render this file, substituting `__DEFAULT_BRANCH__`, `__SONAR_ORG__`, and
`__SONAR_PROJECT_KEY__` (see [../skeleton.md](../skeleton.md)).

```yaml
# Generated by ci-bootstrap. Review before merging.
name: CI
on:
  push:
    branches:
    - __DEFAULT_BRANCH__
  pull_request:
  workflow_dispatch:
permissions:
  contents: read
  packages: write
jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Set up .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: 8.0.x
      - name: Build
        run: |
          dotnet restore
          dotnet build --configuration Release --no-restore
      - name: Test
        run: dotnet test --configuration Release --no-build --verbosity normal
      - name: 'Sonar: set up JDK'
        if: ${{ env.SONAR_TOKEN != '' }}
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
      - name: 'Sonar: install scanner'
        if: ${{ env.SONAR_TOKEN != '' }}
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: dotnet tool install --global dotnet-sonarscanner
      - name: Sonar scan begin
        if: ${{ env.SONAR_TOKEN != '' }}
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: dotnet-sonarscanner begin /k:"__SONAR_PROJECT_KEY__" /o:"__SONAR_ORG__" /d:sonar.host.url="https://sonarcloud.io" /d:sonar.token="$SONAR_TOKEN"
      - name: Sonar build
        if: ${{ env.SONAR_TOKEN != '' }}
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: dotnet build --configuration Release
      - name: Sonar scan end
        if: ${{ env.SONAR_TOKEN != '' }}
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: dotnet-sonarscanner end /d:sonar.token="$SONAR_TOKEN"
      - name: Write default Dockerfile (Push)
        if: github.event_name == 'push'
        run: |
          cat > Dockerfile <<'DOCKERFILE'
          FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
          WORKDIR /src
          COPY . .
          RUN dotnet publish -c Release -o /app

          FROM mcr.microsoft.com/dotnet/aspnet:8.0
          WORKDIR /app
          COPY --from=build /app .
          EXPOSE 8080
          # TODO: set to your published entrypoint dll, e.g. MyApp.dll
          ENTRYPOINT ["dotnet", "app.dll"]
          DOCKERFILE
      - name: Log in to GHCR (Push)
        if: github.event_name == 'push'
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - name: Build and push image (Push)
        if: github.event_name == 'push'
        uses: docker/build-push-action@v6
        with:
          context: .
          push: true
          tags: ghcr.io/${{ github.repository }}:${{ github.sha }}
```

If the repo already has a `Dockerfile`, drop the "Write default Dockerfile" step.
