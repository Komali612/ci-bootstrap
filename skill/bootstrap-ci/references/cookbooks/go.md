# Cookbook: Go (go modules) — `build_system: go`

Language-specific choices:
- **Setup:** Go 1.21 via `actions/setup-go` with module caching. (If the repo's
  `go.mod` pins a newer Go, bump `go-version` to match it.)
- **Build:** `go build ./...` after fetching and verifying modules.
- **Test:** `go test ./...`.
- **Sonar:** use the stack-agnostic `sonarsource/sonarqube-scan-action`.
- **Dockerfile:** multi-stage — build a static binary, then a distroless runtime.

Render this file, substituting `__DEFAULT_BRANCH__`, `__SONAR_ORG__`, and
`__SONAR_PROJECT_KEY__` (see [../skeleton.md](../skeleton.md)).

```yaml
# Generated by ci-bootstrap. Review before merging.
name: CI
on:
  push:
    branches:
    - __DEFAULT_BRANCH__
  pull_request:
  workflow_dispatch:
permissions:
  contents: read
  packages: write
jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version: '1.21'
          cache: true
      - name: Build
        run: |
          go mod download
          go build ./...
      - name: Test
        run: go test ./...
      - name: Sonar scan
        if: ${{ env.SONAR_TOKEN != '' }}
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          SONAR_HOST_URL: https://sonarcloud.io
        uses: sonarsource/sonarqube-scan-action@v4
        with:
          args: >
            -Dsonar.organization=__SONAR_ORG__
            -Dsonar.projectKey=__SONAR_PROJECT_KEY__
      - name: Write default Dockerfile (Push)
        if: github.event_name == 'push'
        run: |
          cat > Dockerfile <<'DOCKERFILE'
          FROM golang:1.21 AS build
          WORKDIR /src
          COPY . .
          RUN CGO_ENABLED=0 go build -o /app/server ./...

          FROM gcr.io/distroless/static
          COPY --from=build /app/server /server
          EXPOSE 8080
          ENTRYPOINT ["/server"]
          DOCKERFILE
      - name: Log in to GHCR (Push)
        if: github.event_name == 'push'
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - name: Build and push image (Push)
        if: github.event_name == 'push'
        uses: docker/build-push-action@v6
        with:
          context: .
          push: true
          tags: ghcr.io/${{ github.repository }}:${{ github.sha }}
```

If the repo already has a `Dockerfile`, drop the "Write default Dockerfile" step.
