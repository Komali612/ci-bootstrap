# Cookbook: Python (pip) — `build_system: pip`

Language-specific choices:
- **Setup:** Python 3.12 via `actions/setup-python` with pip caching.
- **Build:** Python isn't compiled, so "Build" means *install the project and its
  dependencies* — the closest build/install step for the stack.
- **Test:** `pytest`.
- **Sonar:** Python has no build-tool scanner, so use the stack-agnostic
  `sonarsource/sonarqube-scan-action` (the generic scanner CLI), pointed at
  SonarCloud via `SONAR_HOST_URL`.

Render this file, substituting `__DEFAULT_BRANCH__`, `__SONAR_ORG__`, and
`__SONAR_PROJECT_KEY__` (see [../skeleton.md](../skeleton.md)).

```yaml
# Generated by ci-bootstrap. Review before merging.
name: CI
on:
  push:
    branches:
    - __DEFAULT_BRANCH__
  pull_request:
  workflow_dispatch:
permissions:
  contents: read
  packages: write
jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.12'
          cache: pip
      - name: Build
        run: |
          python -m pip install --upgrade pip
          if [ -f requirements-dev.txt ]; then pip install -r requirements-dev.txt; fi
          if [ -f requirements.txt ]; then pip install -r requirements.txt; fi
          if [ -f pyproject.toml ] || [ -f setup.py ]; then pip install -e . || true; fi
      - name: Test
        run: pytest
      - name: Sonar scan
        if: ${{ env.SONAR_TOKEN != '' }}
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          SONAR_HOST_URL: https://sonarcloud.io
        uses: sonarsource/sonarqube-scan-action@v4
        with:
          args: >
            -Dsonar.organization=__SONAR_ORG__
            -Dsonar.projectKey=__SONAR_PROJECT_KEY__
      - name: Write default Dockerfile (Push)
        if: github.event_name == 'push'
        run: |
          cat > Dockerfile <<'DOCKERFILE'
          FROM python:3.12-slim
          WORKDIR /app
          COPY . .
          RUN pip install --no-cache-dir -r requirements.txt
          EXPOSE 8080
          # TODO: set to your app's entrypoint, e.g. ["python", "-m", "app"]
          CMD ["python", "-m", "app"]
          DOCKERFILE
      - name: Log in to GHCR (Push)
        if: github.event_name == 'push'
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - name: Build and push image (Push)
        if: github.event_name == 'push'
        uses: docker/build-push-action@v6
        with:
          context: .
          push: true
          tags: ghcr.io/${{ github.repository }}:${{ github.sha }}
```

If the repo already has a `Dockerfile`, drop the "Write default Dockerfile" step.
